What I build

  • New WordPress sites — five to fifteen pages, built on a lean theme with a page builder you can actually use afterwards. Service pages, location pages, blog, contact forms, the lot.
  • Redesigns — keeping the content and rankings you already have, with redirects mapped properly so you don't lose a decade of SEO on launch day.
  • Speed and Core Web Vitals — image compression and WebP conversion, caching, unused CSS and JS removed, plugin audit, database clean-up. Usually the single cheapest ranking win available.
  • Technical SEO setup — Rank Math or Yoast configured properly (not left on defaults), XML sitemaps, schema, Search Console and GA4 connected and verified.
  • Fixes and rescue jobs — hacked sites, white screens, broken updates, a theme the last developer disappeared with.

How I keep it fast

  • Lean theme, minimal plugins — every plugin is a request, and most sites are running four that could be one.
  • Images converted to WebP, sized for the container they sit in, lazy-loaded below the fold.
  • Critical CSS inlined, render-blocking scripts deferred, fonts self-hosted and preloaded — the same techniques used to build this site.
  • Caching and CDN configured for your actual host rather than copied from a YouTube tutorial.
  • Measured on real pages in PageSpeed Insights before and after, so the improvement is a number, not a claim.

Questions

Before you ask.

Do you use a page builder or code it by hand?

Both, depending on what you need afterwards. If you want to edit the site yourself, I build with a lightweight builder like Elementor or Bricks on a lean theme so you can change text and images without me. If speed is the absolute priority and you won't be editing, hand-coded blocks are faster.

Will my rankings drop when you redesign the site?

Not if the migration is done properly. Before anything goes live I map every existing URL to its new equivalent and put 301 redirects in place, keep the content that is already ranking, and re-submit the sitemap. The risk comes from redesigns where nobody does that step.

Do you offer hosting or maintenance?

I don't resell hosting — you own your hosting account and your domain, which is how it should be. I will recommend a host that suits your traffic and set everything up on it. Ongoing maintenance can be arranged monthly if you want it.

Can you fix a site somebody else built?

Yes, that is a good share of the work. Send me the URL and admin access and I will tell you honestly whether it is worth fixing or whether a rebuild would cost you less in the long run.

Is SEO included or is it extra?

On-page SEO is included in every build — proper titles, headings, structure, schema and speed. A deeper campaign with keyword research across a full site and ongoing content is the SEO audit service, which pairs naturally with a build.
